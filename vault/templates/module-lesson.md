## Guidelines for Lesson Content

**Voice and style:**
- Conversational but precise
- "Here's what actually happens" explanations
- Connect to mental models from JS/TS when helpful
- Depth over breadth — go deep on key concepts

**Structure:**
- Start with fundamentals (memory, compilation, runtime behavior)
- Build from concrete to abstract
- Include comparison tables for quick reference
- End sections with "Your notes" for user reflection

**Code examples:**
- Runnable, realistic snippets (not toy examples)
- Include output where helpful
- Show both correct usage and common mistakes
- Reference separate code files for longer examples

**Cross-language connections:**
- Compare to JavaScript/TypeScript (user's primary mental model)
- Highlight where languages diverge (e.g., Go value semantics vs JS reference semantics)
- Note idioms that are language-specific vs universal patterns

**Callouts:**
- Use for gotchas, performance notes, and key insights
- Format: bullet points or short paragraphs, never long prose

**"Your notes" sections:**
- Leave empty for user to fill during learning
- One per major section
- User adds personal insights, aha moments, and connections
